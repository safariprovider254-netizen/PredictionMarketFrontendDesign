# Polka.trade — Design Guidelines

## Aesthetic: Broadcast Utility

A sportsbook-informed prediction market. Information-dense, structured, legible under pressure. Every pixel earns its place.

## Color Tokens

| Token | Value | Use |
|---|---|---|
| Light Mineral | `#F2F0EA` | Page background |
| Warm White | `#FAF9F6` | Alternate band / card surface |
| Ink Navy | `#152B43` | Primary text, rules, headers |
| Pale Sky | `#DCE7EF` | Alternate band, selected states |
| Signal Orange | `#E15B36` | LIVE indicator, active, urgent only |

## Typography

- **Headings / Odds / Labels**: Barlow Condensed — sturdy condensed grotesque, uppercase, tight tracking
- **Body / Controls / Rows**: Geist Sans — compact, neutral, highly legible at small sizes
- **Tabular data**: Geist Mono — odds, volumes, percentages

## Spacing & Shape

- Radii: 0–4px only. No rounded cards.
- Rules: 1px solid `#152B43` at 15–20% opacity
- Shadows: none
- Density: tight rows, 8–12px vertical padding per row
- Bands: alternate `#FAF9F6` (warm white) and `#DCE7EF` (pale sky) for rhythm

## Structure

- Sticky top header with logo + primary nav
- Left sidebar: category filters (Sports, Politics, Crypto, Entertainment, Global, Kenya)
- Main column: stacked full-width market bands
- Right rail: top movers, recent bets, volume leaders
- Orange dot = LIVE / active market

## Never

- Near-black full-canvas backgrounds
- Rounded card stacks or gradient backgrounds
- Glow, translucent panels, or shadows
- Red/amber together
- Edge-to-edge cinematic artwork
